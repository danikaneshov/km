# ГЛОБАЛЬНЫЙ ПРОМПТ ДЛЯ ИИ: БОТ-ПОМОЩНИК КАЛЬЯННОГО МАСТЕРА

Тебе предстоит написать Telegram-бота (и ИИ-ассистента на базе LLM), который будет служить умным помощником для кальянного мастера. 
Это не просто записная книжка, это система, которая понимает контекст работы кальянного мастера и ведет учет по двум независимым направлениям. Ниже описана исключительно бизнес-логика того, как это должно работать.

## 1. БАЗА ДАННЫХ 1: СКЛАД (ПРИХОДЫ)
Эта база данных полностью изолирована и нужна только для одной цели — фиксации поставок.
- **Логика**: Когда на склад физически привозят новый табак или угли, мастер сообщает об этом боту.
- **Функционал**: Бот просто сохраняет информацию о том, в какую дату был приход, и подробный список того, что именно пришло (какие вкусы, бренды, граммовки).
- **Связь**: Эта база никак не пересекается со списаниями или курением. Это чисто история пополнения склада.

## 2. БАЗА ДАННЫХ 2: БАЛАНС "ИЗЛИШКИ И СТАФФ"
Это главная и самая активная часть функционала. В заведении есть специфика: часто гости заказывают дорогой кальян (например, за 10 тысяч), в стоимость которого входят сразу 2 чаши. Гость платит за обе, но вторую в итоге не выкуривает, и мастер её даже не забивает. По документам и кассе чаша прошла, а по факту табак и угли остались целыми. Это формирует «Излишек».

### Понятие "Излишек" (Нескуренная чаша)
- Когда гость не выкурил оплаченную чашу, мастер говорит боту: "Излишек 1 чаша" (или "+ чаша").
- У бота в настройках базы данных *единожды* задан шаблон (например: 1 чаша = 20 грамм табака и 4 угля). 
- Бот берет этот шаблон и автоматически зачисляет на виртуальный "баланс мастера" это количество ресурсов.

### Понятие "Стафф-кальян" (Расход)
- Стафф-кальян — это когда кальянные мастера забивают кальян для себя (на смене). По сути, они выкуривают те самые нескуренные гостями чаши (излишки).
- Когда мастер курит стафф, он говорит об этом боту. Бот списывает со счета излишков ресурсы (табак и угли), тем самым возвращая баланс мастера к нулю.

### Задачи второй базы данных:
1. **Текущий баланс**: Мастер в любой момент может спросить у бота: "Сколько у нас сейчас излишков?" Бот должен показать, сколько еще таких "недокуренных чаш" (или граммов/углей) осталось на балансе, которые мастера могут скурить как стафф.
2. **История по дням**: Бот должен вести четкую историю по дням. Мастер может запросить стату: "Покажи историю за эту неделю", и бот должен выдать, в какой день сколько чаш ушло в излишек (не докурили гости), и сколько чаш было выкурено как стафф (покурили мастера).

## 3. СТЕК ТЕХНОЛОГИЙ
- **Язык**: Python
- **Фреймворк**: aiogram (асинхронный Telegram-бот)
- **База данных**: MongoDB (драйвер motor)
- **AI Интеграция**: Gemini (или аналог) с поддержкой Function Calling, чтобы ИИ сам понимал из текста или голосового сообщения, в какую базу делать запись и какой инструмент вызывать.

## 4. ДОСТУП И АВТОРИЗАЦИЯ
- В `.env` есть `ALLOWED_TELEGRAM_ID` — основной аккаунт, который всегда имеет доступ к боту.
- Также в `.env` есть `SECRET_PHRASE` (секретная фраза). Механика: если кто-то с любого (рандомного) Telegram-аккаунта напишет боту эту фразу, бот должен:
  1. **Немедленно удалить сообщение** с фразой из чата (для конспирации, чтобы никто не увидел).
  2. **Добавить этот Telegram ID в список авторизованных пользователей** (в базу admins).
  3. С этого момента этот аккаунт получает полный доступ к функционалу бота.
- Все остальные пользователи, не прошедшие авторизацию, не должны получать ответы от бота.

## 5. ЛОГ-КАНАЛ
- В `.env` есть `LOG_CHANNEL_ID`. Это Telegram-канал, куда бот отправляет уведомления о каждой записи (приход на склад, излишек, стафф и т.д.) для общего контроля.

## 6. ХАРАКТЕР БОТА
- По рабочим вопросам (склад, излишки, стафф) — отвечает коротко, четко, по делу.
- Если пользователь пишет что-то, не связанное с работой ("как дела", "привет", "погода") — бот отвечает агрессивно-грубо с матом, заставляя вернуться к рабочим вопросам.
- Формат текста: только HTML теги (<b>, <i>), никакого Markdown (Telegram HTML parse mode).

## 7. СПРАВОЧНИК БРЕНДОВ
Бот должен распознавать сленговые сокращения брендов табака и исправлять их на эталонные:
- бб → BlackBurn, дс → DarkSide, мастхэв → MustHave, краун → Crown
- Полный список: BlackBurn, MustHave, DarkSide, Crown, Cocoloco, Sebero, Vkuss, Jam, Hell, Overdose, Sarma.
